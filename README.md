# 🏎️ TURBO POYGA - 2D Pro Extreme Racing Game

HTML5 Canvas, CSS3 va sof JavaScript (Vanilla JS) yordamida yaratilgan to'liq poyga o'yini.
Hech qanday qo'shimcha o'rnatish yoki dastur talab qilinmaydi — shunchaki `index.html` faylini brauzerda oching va o'ynang!

---

## 🚀 Qanday o'ynash kerak?
1. Papkadagi `index.html` faylini istalgan brauzerda (Chrome, Edge, Firefox, Safari) oching.
2. Menyuda o'zingizga yoqqan **Trassa (Yo'l)** va **Moshina**ni tanlang.
3. Botlar sonini (1 tadan 5 tagacha) va aylanishlar sonini belgilang.
4. **"POYGANi BOSHLASH"** tugmasini bosing!

---

## 🎮 Boshqaruv tugmalari:

| Tugma | Vazifasi |
| :--- | :--- |
| **W** yoki **Yuqoriga o'q (↑)** | Oldinga gaz berish (Tezlashuv) |
| **S** yoki **Pastga o'q (↓)** | Tormoz berish / Orqaga yurish |
| **A / D** yoki **← / →** | Rulni chapga / o'ngga burish |
| **Shift** yoki **Bo'sh joy (Space)** | ⚡ **NITRO** turbo tezlanish |
| **R** | Moshinani trassaga qayta tiklash (adashib ketsangiz) |
| **P** yoki **Esc** | O'yinni to'xtatish (Pause) |
| **M** yoki ekrandagi karnaycha | Ovozni yoqish / o'chirish |

> 📱 **Mobil / Planshet:** Telefon yoki planshetda ochilganda ekranda avtomatik ravishda sensorli (touch) boshqaruv tugmalari paydo bo'ladi.

---

## 🛣️ Mavjud Trassalar (Yo'llar):
1. **Shahar Halqasi (City Grand Prix)** — Keng asfalt yo'llar, shahar manzaralari, o'rganish uchun qulay yumshoq burilishlar.
2. **Cho'l Shamoli (Desert Dunes)** — Issiq qum barxanlari, uzun drift burilishlari, kaktuslar va toshlar.
3. **Neon Megapolis (Cyberpunk Night)** — Tungi kiberpank shahar, neon to'siqlar, yoritilgan trassa va chiroyli chicanelar.
4. **Tog' Dovoni (Mountain Pass)** — Serpentine burilishlar, qoyalar va qattiq tormoz zonalariga ega qiyin trassa.

---

## 🚘 Moshinalar:
- **Qizil Bo'ri (Red Fury):** Balansli sportkar, yuqori tezlanish va barqarorlik.
- **Moviy Chaqmoq (Blue Lightning):** Maksimal tezlikka yo'naltirilgan giperkar.
- **Zahar Yashil (Poison Drift):** Drift va keskin burilishlar ustasi.
- **Oltin Qoplon (Gold Beast):** Ekstremal quvvat va yuqori boshqaruvchanlik.

---

## 🤖 Raqib Botlar (AI):
- O'yinda siz bilan birga poygalashuvchi aqlli botlar mavjud.
- Botlar trassani taniydi, burilishlarda tormoz beradi, to'g'ri yo'llarda nitroni ishlatadi va sizni quvib o'tishga harakat qiladi.
- Botlar bilan to'qnashganda haqiqiy fizika (zarba kuchi, sakrash, uchqunlar va ovoz) ishlaydi.

---

## 🔊 Ovoz va Effektlar:
- Dvigatel ovozi (tezlikka qarab ohangi o'zgaradi).
- Shinalarning sirpanish (drift/skid) ovozi va asfaltdagi qora izlar (skid marks).
- To'qnashuv ovozlari va uchqunlar.
- Nitro olov effekti va raketa tovushi.
- 3, 2, 1, KETDIK hisob ovozlari va marradagi g'alaba fanfari.
- Barcha ovozlar Web Audio API yordamida to'g'ridan-to'g'ri kodda sintez qilinadi (hech qanday tashqi audio fayl yuklash shart emas).
